CUDDLE PASSPORT 3.1

Installeren op GitHub Pages:
1. Pak de ZIP uit.
2. Open de map Cuddle_Passport_3.1.
3. Upload index.html naar je GitHub-repository en vervang het oude index.html-bestand.
4. Commit de wijziging en wacht even tot GitHub Pages is bijgewerkt.

Lokaal testen:
1. Open index.html in Chrome of Edge.
2. Voor de realistische wereldkaart is internet nodig (Leaflet + OpenStreetMap).

Functies: knuffels toevoegen met foto en verhaal, bekijken/bewerken/verwijderen, favorieten, zoeken/filteren, kaartmarkeringen, reizen, profiel, landendoel/badges en JSON-back-up export/import.

Let op: gegevens worden in de browser van dit apparaat opgeslagen. Gebruik de back-upfunctie om ze over te zetten of veilig te bewaren. De kaart plaatst een knuffel standaard ongeveer in het landcentrum; nauwkeurige plaatsmarkeringen kunnen later worden toegevoegd.
